> ⚠️ Репозиторий ПУБЛИЧНЫЙ — не коммитить секреты и клиентские данные.

- **Что это:** автоматизация Google Таблицы «Список оборудования» для клиентских проектов барной эргономики: выпадающий список и автозаполнение характеристик.
- **Production:** Google Таблица (ссылка в `README.md`).
- **Как проверить:** выбрать позицию в столбце B таблицы — автозаполнение колонок C, E–H.
- **Контур выпуска:** код `apps-script/` вручную переносится в связанный Google Apps Script таблицы «Список оборудования».
- **Доказательство версии в production:** Git commit и версия Apps Script deployment сейчас не связываются; проверка — сценарий автозаполнения непосредственно в таблице.
- **Откат:** автоматического отката нет; вернуть предыдущую версию через историю Apps Script после предварительно сохранённого commit SHA.
- **Секреты:** локальный `.env` (не в git).
- **Соседние системы:** Google Sheets.
- **Главная дока:** `README.md`.
