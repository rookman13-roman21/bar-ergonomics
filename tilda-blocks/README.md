## Как вставить в Tilda

1. Откройте редактор страницы Tilda
2. Добавьте блок → найдите **T123** (HTML-блок) или используйте **Zero Block → Вставить HTML**
3. Скопируйте содержимое нужного файла → вставьте в поле HTML
4. Сохраните

> **Важно:** Шрифт Mulish подключается **только** в блоке `01-hero.html` — он должен быть первым на странице.  
> Остальные блоки используют его без повторного подключения.

## Особенности блоков

### `03-deliverables.html` — 6 карточек
- SVG-иконки убраны, карточки начинаются с номера (01–05, Бонус)
- Сетка 3×2, адаптивная

### `05-portfolio.html` — Динамическая 3D-витрина
- Получает все публичные живые кейсы из `https://drawings.barista-school.ru/api/public/cases`; Битрикс остаётся единственным источником состава, описаний и фотографий.
- Карточки листаются горизонтально, а клик открывает историю проекта с альбомами «Визуализация готовой планировки» и «Помещение до проекта». Красная CTA ведёт в 3D-клиент в новой вкладке.
- API намеренно разрешает CORS только для опубликованного `https://baristaschool.ru`. В Tilda preview (`*.tilda.ws`), локальном и Vercel-preview загрузка кейсов не работает по задумке: там остаётся безопасная ссылка на полную витрину.
- Попап повторяет пользовательский сценарий витрины Viewer, но реализован отдельно для Tilda. При изменении сценария нужно обновлять обе реализации; Tilda-копия принимается вручную на опубликованной странице.

### `06-expert.html` — Биография специалиста
- Двухколоночный макет: фото слева (aspect-ratio 3/4 + бейдж), контент справа
- Факты с галочками, статистика (15+ лет / 5 лет кафе), CTA
- JS: IntersectionObserver scroll-reveal

### `08-faq.html` — FAQ-аккордеон
- 7 вопросов-ответов в `<details>/<summary>`
- JS: sticky левая колонка + плавная анимация раскрытия

## Что нужно заменить перед публикацией

- `01-hero.html` → `src` в теге `<img>` — вставьте реальное фото бара
- Создать на Тильде блок с формой с якорем `consalt`
- При необходимости — обновить фото в `06-expert.html` (текущее: Tilda CDN)
- При необходимости — обновить цену в `07-price.html`
- После изменения блока 05 публиковать Tilda только после CORS-smoke Viewer. Откат — история страницы Tilda или предыдущая версия блока из Git.
