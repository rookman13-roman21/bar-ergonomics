# Барная эргономика — автозаполнение оборудования

Автоматизация Google Таблицы «Список оборудования» для клиентских проектов по барной эргономике.

**Таблица:** https://docs.google.com/spreadsheets/d/1XSVheSQkxr8H87Fm-c7JPwz472SBLWd6p72GH4gYALM/edit?gid=1161409919#gid=1161409919

---

## Что делает

- **Выпадающий список** в столбце B «Название» — все позиции из библиотеки оборудования
- **Автозаполнение** при выборе позиции: C (производитель), E (размеры), F (кВт), G (вода), H (цена)
- **Боковая панель** с выбором по категориям: Кофемашины → Кофемолки → Холодильное и т.д.
- **Категории** добавлены в «Библиотеку оборудования» (столбец I)

## Установка (один раз)

### Шаг 1: Python — настройка таблицы

```bash
cd bar-ergonomics
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python3 scripts/setup_sheet.py
```

Скрипт добавит столбец «Категория» в библиотеку и установит выпадающие списки в столбец B «Оборудование».

### Шаг 2: Google Apps Script

1. Откройте таблицу → **Расширения → Apps Script**
2. В редакторе переименуйте `Code.gs` → вставьте содержимое `apps-script/Code.gs`
3. Нажмите **➕ Новый файл → HTML** → назовите `Dialog` → вставьте содержимое `apps-script/Dialog.html`
4. Нажмите **💾 Сохранить** (Ctrl+S)
5. В выпадающем списке функций выберите `setupTriggers` → нажмите **▶ Выполнить**
6. Разрешите запрос прав доступа
7. Обновите страницу таблицы — появится меню **«🔧 Оборудование»**

## Как пользоваться

### Способ 1: Выпадающий список (быстро)

1. Перейдите на вкладку **«Оборудование»**
2. Кликните на ячейку в столбце **B** → выберите из выпадающего списка
3. Поля C, E, F, G, H заполнятся автоматически ⚡
4. Введите количество в столбце **D** вручную

### Способ 2: Панель по категориям (удобно)

1. Меню **«🔧 Оборудование» → «➕ Добавить из библиотеки»**
2. Выберите строку (позицию)
3. Выберите категорию → в списке появятся только подходящие модели
4. Выберите модель → увидите предпросмотр характеристик
5. Нажмите **«Добавить в таблицу»**

### Добавить новое оборудование в библиотеку

1. Откройте вкладку **«Библиотека оборудования»**
2. Добавьте строку: A=Название, B=Производитель, D=Размеры, E=кВт, F=Вода, G=Цена, I=Категория
3. В таблице: меню **«🔧 Оборудование» → «🔄 Обновить выпадающие списки»**
4. Или запустите снова `setup_sheet.py` — он пересоздаст список и добавит категорию

## Повторный запуск setup_sheet.py

Скрипт идемпотентен — можно запускать сколько угодно раз:
- Не перезаписывает уже заполненные категории (пропускает строки, где I уже заполнено)
- Пересоздаёт выпадающий список на B2:B`MAX_EQ_ROWS` (константа = 200, с актуальным списком позиций)

## Как пользоваться меню

| Пункт меню | Действие |
|------------|----------|
| ➕ Добавить из библиотеки | Открывает боковую панель |
| 🔄 Обновить выпадающие списки | Пересобирает B2:B50 из библиотеки (алфавит) |
| 🔢 Обновить итоги | Добавляет/обновляет строку ИТОГО с `=SUM(I2:I...)` |
| 🗑 Очистить строку | Очищает выбранную строку (B, C, E–H) |
| 🔒 Защитить библиотеку | Включает режим предупреждения на вкладке библиотеки |
| ❓ Справка | Краткая инструкция |
